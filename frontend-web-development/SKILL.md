# Frontend Web Development

Deliver interfaces that fit the existing product and work across common input methods and screen sizes.

## Workflow

- Inspect the framework, component patterns, styling system, routing, data fetching, and design conventions before editing.
- Clarify the primary user flow and keep its default path understandable.
- Implement loading, empty, error, success, and disabled states when relevant.
- Use semantic HTML, accessible names, keyboard operation, visible focus, sufficient contrast, and responsive layouts.
- Keep state and network behavior predictable; handle slow responses and avoid stale or duplicate updates where relevant.
- Follow existing bundle, rendering, and image practices to protect performance.
- Verify rendered behavior in the available environment and report what was and was not checked.

## Boundaries

- Do not introduce a new design system or dependency without a clear project need.
- Do not hide important errors from users or create controls that are inaccessible by keyboard.
- Do not assume React, Next.js, or a specific framework unless the project uses it.
